# MyBlog Admin

MyBlog 博客系统的后台管理前端，基于 Vue 3、TypeScript、Vite 与 Ant Design Vue 构建，数据通过 Java 后端持久化到 PostgreSQL。

## 内容管理

后台以 `myblog` 前台实际展示结构为准，只管理可重复增删或具有相同结构的数据集合，共七个模块：

- 技术栈：技术卡片和熟练度。
- 我做过的项目：卡片标题/摘要、详情标题/摘要、正文、图片集，以及关联的 myLab 记录。
- 我的足迹：按前端固定城市 ID 编辑城市详情、图片和可选跳转按钮，不管理城市增删与排序。
- 我的爱好：最多五张右侧爱好卡片，不管理 Time 数据。
- Vibe Coding：右侧 AI 工具；左侧图片、Logo 与动效由前端代码负责。
- myLab：筛选标签、研究记录卡片和由章节/段落组成的详情页。
- 支持页面：访问基数、手动点赞数和浏览基数。

所有页面大标题和描述、关于我全部内容、足迹地图与城市列表、爱好 Time 面板、支持页运行时间与联系/备案信息均固定在博客前端代码中。

内容编辑采用结构化表单，支持媒体库选图、列表排序、启用/停用、草稿保存、发布、下线、历史版本和回滚。草稿不会直接影响前台；前台只读取已发布快照。

## 开发

```bash
npm install
npm run dev
npm run build
```

接口基础地址由 `VITE_API_BASE_URL` 配置，默认使用 `/api/v1`。生产访问路径由根目录
`.env` 的 `ADMIN_ROUTE` 在 Docker 构建时注入，默认 `/admin`。登录账号由后端初始化配置提供，不在前端保存演示密码。
